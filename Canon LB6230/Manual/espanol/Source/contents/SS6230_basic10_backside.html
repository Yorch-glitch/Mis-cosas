        0KXF-009
        Parte trasera
         
         
        Ranuras de ventilación
        El aire del interior del equipo se expulsa para refrigerar la parte interna del equipo. Tenga en cuenta que si coloca objetos delante de las ranuras de ventilación el aire no podrá entrar ni salir. Instalación
        Tapa trasera
        Ábrala para sacar el papel atascado. Eliminación de atascos de papel
        Etiqueta de identificación
        La etiqueta muestra el número de serie, que es necesario para realizar consultas sobre el equipo. Cuando no puede solucionarse un problema
        Puerto USB
        Conecte un cable USB cuando conecte el equipo con un ordenador.
        Botón de restauración
        También puede mantener apretada esta tecla mientras enciende el equipo para inicializar las opciones de administración del sistema. Inicialización mediante el botón de restauración
        Indicador ACT
        Parpadea cuando se están enviando y recibiendo datos a través de la red cableada.
        Puerto LAN
        Utilice un cable de LAN para conectarse a un concentrador (o a un router). Conexión a una red cableada
        Indicador LNK
        Se ilumina cuando el equipo está conectado a la red cableada.
        Enchufe
        Conecte el cable de alimentación.
