        Configurando o SNTP
        O SNTP (Simple Network Time Protocol) permite ajustar o relógio do sistema usando um servidor de horário na rede. Quando o SNTP é usado, o sistema verificar periodicamente o servidor de horário, assim, o relógio do sistema está sempre preciso. A hora é baseada no Tempo Universal Coordenado (UTC), e sendo assim, é necessário especificar o fuso horário antes de configurar o SNTP (Timer Settings).
        O SNTP da impressora suporta ambos os servidores, NTP (versão 3) e SNTP (versões 3 e 4).
        1
        Inicie o Remote UI e faça o logon no modo Administrador Sistema. Iniciando o Remote UI
        2
        Clique em [Settings/Registration].
        3
        Clique em [Network Settings] [TCP/IP Settings].
        4
        Clique em [Edit] em [SNTP Settings].
        5
        Marque a caixa de seleção [Use SNTP] e digite as informações necessárias.
        [Use SNTP]
        Marque a caixa de seleção para usar o NSPT para sincronização. Desmarque a caixa de seleção se não quiser usar esta função.
        [NTP Server Name]
        Digite o endereço IP do servidor NTP ou SNTP. Se um servidor DNS estiver disponível na rede, você pode digitar um "<nome de host>.<nome de domínio>" (FQDN) de até 255 caracteres alfanuméricos (exemplo: "ntp.exemplo.com").
        [Polling Interval]
        Digite um intervalo de 1 a 48 horas para especificar a frequência de consulta do servidor de horário.
        6
        Clique em [OK].
         
        Testando a comunicação com o servidor NTP/SNTP
        É possível testar a comunicação da impressora com o servidor de horário registrado via SNTP. Clique em [Settings/Registration]  [Network Settings]  [TCP/IP Settings] para exibir [SNTP Settings], depois clique em [Check NTP Server]. Se uma conexão apropriada foi estabelecida, o resultado é exibido conforme mostrado abaixo. (Observe que esta operação verifica somente a conexão. Ela não ajusta o relógio do sistema.)
        Sincronizando com o horário definido no computador
        É possível notificar a impressora do horário definido em seu computador e sincronizar com aquele horário. Configure as definições de notificação de horário na Janela de Status da Impressora.
        1
        Selecione a impressora clicando na bandeja do sistema.
        2
        Selecione [Opções]  [Preferências (Administradores)].
        3
        Marque a caixa de seleção [Notificar Hora à Impressora] e clique em [OK].
