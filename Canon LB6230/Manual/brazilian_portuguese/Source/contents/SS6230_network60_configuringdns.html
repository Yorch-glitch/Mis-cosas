        Configurando o DNS
        O DNS (Domain Name System) fornece um serviço para a resolução de nome associado a um nome de host (ou domínio) com um endereço IP. Configure as definições de opção DNS, mDNS ou DHCP conforme necessário e de acordo com sua rede. Observe que os procedimentos para a configuração do DNS são diferentes para o IPv4 e o IPv6.
         
        1
        Inicie o Remote UI e faça o logon no modo Administrador Sistema. Iniciando o Remote UI
        2
        Clique em [Settings/Registration].
        3
        Clique em [Network Settings] [TCP/IP Settings].
        4
        Configure as definições de DNS
        Configurando as definições de DNS do IPv4
        1
        Clique em [Edit] em [IPv4 Settings].
        2
        Defina as configurações de DNS do IPv4.
         [DNS Settings]
        [Primary DNS Server Address]
        Digite o endereço IP do servidor DNS.
        [Secondary DNS Server Address]
        Quando houver um servidor de DNS secundário, digite seu endereço IP.
        [Host Name]
        Digite até 47 caracteres alfanuméricos para o nome do host da impressora que será registrada no servidor DNS.
        [Domain Name]
        Digite até 47 caracteres alfanuméricos para o nome do domínio pertencente à impressora, como "exemplo.com".
        [DNS Dynamic Update]
        Marque a caixa de seleção para atualizar automaticamente os registros de DNS sempre que a associação entre o endereço IP da impressora e seu nome do host for alterado (por exemplo, em um ambiente DHCP). Para especificar o intervalo entre as atualizações, digite as horas na caixa de texto [DNS Dynamic Update Interval]. Desmarque a caixa de seleção se não quiser usar a atualização dinâmica.
         [mDNS Settings]
        [Use mDNS]
        Adotado por serviços como o Bonjour, o mDNS (DNS multicast) é um protocolo de associação de nome do host com um endereço IP sem usar DNS. Marque a caixa de seleção para ativar o mDNS e digite o nome do mDNS na caixa de texto [mDNS Name]. Desmarque a caixa de seleção se não quiser usar o mDNS.
         [DHCP Option Settings]
        [Acquire Host Name]
        Marque a caixa de seleção para ativar a Opção 12 para obter o nome do host a partir do servidor DHCP. Desmarque a caixa de seleção se não quiser usar esta função.
        [DNS Dynamic Update]
        Marque a caixa de seleção para ativar a Opção 81 para atualizar dinamicamente os registros do DHCP. Desmarque a caixa de seleção se não quiser usar esta função.
        3
        Clique em [OK].
        Configurando as definições de DNS do IPv6
        1
        Clique em [Edit] em [IPv6 Settings].
        2
        Defina as configurações de DNS do IPv6.
        A [Use IPv6] caixa de seleção deve ser marcada para configurar as definições. Definindo endereços IPv6
         [DNS Settings]
        [Primary DNS Server Address]
        Digite o endereço IP do servidor DNS. Endereços que começam com "ff" (endereços multicast) e endereços de loopback (::1) não podem ser inseridos.
        [Secondary DNS Server Address]
        Quando há um servidor de DNS secundário, digite seu endereço IP. Endereços que começam com "ff" (endereços multicast) e endereços de loopback (::1) não podem ser inseridos.
        [Use Same Host Name/Domain Name as IPv4]
        Marque a caixa de seleção para usar as mesmas definições usadas no IPv4. O nome do host e nome de domínio usados no IPv4 serão definidos automaticamente depois que a impressora for reinicializada. Desmarque a caixa de seleção se quiser usar definições diferentes do IPv4.
        [Host Name]
        Digite até 47 caracteres alfanuméricos para o nome do host da impressora que será registrada no servidor DNS.
        [Domain Name]
        Digite até 47 caracteres alfanuméricos para o nome do domínio pertencente à impressora, como "exemplo.com".
        [DNS Dynamic Update]
        Marque a caixa de seleção para atualizar automaticamente os registros de DNS sempre que a associação entre o endereço IP da impressora e seu nome de host altera (por exemplo, em um ambiente DHCP). Para especificar os endereços que você deseja registrar com o servidor de DNS, marque uma ou mais das caixas de seleção de [Register Manual Address], [Register Stateful Address] e [Register Stateless Address]. Para especificar o intervalo entre as atualizações, digite as horas na caixa de texto [DNS Dynamic Update Interval]. Desmarque a caixa de seleção se não quiser usar a atualização dinâmica.
         [mDNS Settings]
        [Use mDNS]
        Adotado por serviços como o Bonjour, o mDNS (multicast DNS) é um protocolo de associação de nome do host com um endereço IP sem usar DNS. Marque a caixa de seleção para ativar o mDNS. Desmarque a caixa de seleção se não quiser usar o mDNS.
        [Use Same mDNS Name as IPv4]
        Marque a caixa de seleção para usar as mesmas definições usadas no IPv4. O nome do mDNS usado no IPv4 será definido automaticamente depois que a impressora for reinicializada. Desmarque a caixa de seleção e digite um nome em [mDNS Name] se quiser usar definições diferentes do IPv4.
        3
        Clique em [OK].
        5
        Reinicie a impressora.
        Desligue a impressora, espere pelo menos 10 segundos e ligue novamente.
