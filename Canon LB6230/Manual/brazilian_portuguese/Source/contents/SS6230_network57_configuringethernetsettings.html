        Definindo suas configurações de Ethernet
        Ethernet é um padrão de comunicação de dados em uma LAN. É possível definir o modo de comunicação (Half Duplex/Full Duplex) e o tipo de Ethernet (10BASE-T/100BASE-TX). A configuração padrão de fábrica, o modo de comunicação e o tipo de Ethernet são detectados automaticamente. Em geral, as configurações de Ethernet podem ser usadas como se encontram, mas use o seguinte procedimento para especificar manualmente as configurações, conforme necessário.
        1
        Inicie o Remote UI e faça o logon no modo Administrador Sistema. Iniciando o Remote UI
        2
        Clique em [Settings/Registration].
        3
        Clique em [Network Settings] [Ethernet Driver Settings].
        4
        Clique em [Edit].
        5
        Desmarque a caixa [Auto Detect], e defina as configurações Ethernet.
        [Auto Detect]
        Desmarque a caixa de seleção para definir manualmente as configurações de Ethernet. Marque a caixa de seleção para detectar automaticamente as configurações de Ethernet.
        [Communication Mode]
        Selecione o modo de comunicação da Ethernet.
        [Half Duplex]
        Alternativamente, envia e recebe dados de comunicação. Selecione esta opção quando a impressora estiver conectada a um dispositivo de rede usando o half duplex.
        [Full Duplex]
        Simultaneamente envia e recebe dados de comunicação. Use esta configuração para a maioria dos ambientes.
        [Ethernet Type]
        Selecione [10BASE-T] ou [100BASE-TX] como o tipo de Ethernet.
        6
        Clique em [OK].
        7
        Reinicie a impressora.
        Desligue a impressora, espere pelo menos 10 segundos e ligue novamente.
