        Parte traseira
         
         
        Aberturas de ventilação
        O ar interno da impressora é ventilado para o resfriamento do interior da impressora. Colocar objetos em frente às aberturas impede a ventilação. Instalação
        Tampa traseira
        Abra para remover o papel obstruído. Eliminando os atolamentos de papel
        Etiqueta de classificação
        A etiqueta mostra o número de série, que é necessário ao realizar indagações sobre a impressora. Quando um problema não puder ser resolvido
        Porta USB
        Conecte um cabo USB quando conectar a impressora e um computador.
        Botão reset
        Você pode pressionar esta tecla ao LIGAR a impressora para inicializar as configurações de gerenciamento do sistema. Inicialização com o botão de reset
        Indicador ACT
        Pisca quando os dados são enviados e recebidos via LAN com fio.
        Porta LAN
        Use um cabo de rede para conectar a um hub (ou roteador). Conectando a uma rede LAN sem Fio
        Indicador LNK
        Acende quando a impressora está conectada a uma LAN com fio.
        Soquete de alimentação
        Conecte o cabo de alimentação.
