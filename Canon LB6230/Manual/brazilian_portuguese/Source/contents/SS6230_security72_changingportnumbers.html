        Alterando os números de portas
        As portas servem como pontos de extremidades da comunicação com outros dispositivos. Normalmente, os números de porta convencional são usados para os protocolos principais, mas os dispositivos que usam esses números de porta estão vulneráveis a ataques, pois esses números de portas são bem conhecidos. Para aprimorar a segurança, alguns administradores de rede precisam alterar os números de porta. Quando um número de porta é alterado, o novo número deve ser compartilhado com os dispositivos de comunicação, como os computadores e servidores. Se um número de porta é alterado, defina-o também nesta impressora.
        1
        Inicie o Remote UI e faça o logon no modo Administrador Sistema. Iniciando o Remote UI
        2
        Clique em [Settings/Registration].
        3
        Clique em [Network Settings] [TCP/IP Settings].
        4
        Clique em [Edit] em [Port Number Settings].
        5
        Altere o número de porta e clique [OK].
        [LPD]/[RAW]
        Altera a porta usada para a impressão LPD ou RAW. Para obter mais informações sobre esses protocolos, consulte Configurando os protocolos de impressão e serviços da web.
        [HTTP]
        Altera a porta usada pelo protocolo HTTP. O protocolo HTTP é usado para a comunicação através da rede, como ocorre quando você acessa a impressora via Remote UI.
        [SNMP]
        Altera o número da porta usada pelo protocolo SNMP. Para obter mais detalhes sobre o protocolo SNMP, consulte Monitorando e controlando a impressora com SNMP.
        [WSD Multicast Discovery]
        Altera o número da porta usada para descoberta por WSD multicast. Para obter mais detalhes sobre o WSD, consulte Configurando os protocolos de impressão e serviços da web.
        [Multicast Discovery]
        Altera o número da porta usada para descoberta por SLP multicast. Para obter mais detalhes sobre o SLP, consulte Configurando a comunicação SLP com o imageWARE.
        6
        Reinicie a impressora.
        Desligue a impressora, espere pelo menos 10 segundos e ligue novamente.
