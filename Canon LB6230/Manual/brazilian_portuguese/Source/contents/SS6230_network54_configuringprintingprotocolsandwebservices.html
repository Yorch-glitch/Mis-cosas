        Configurando os protocolos de impressão e serviços da web
        A seguir, explicamos como configurar os protocolos de impressão para a impressão de documentos a partir de computadores. Os protocolos suportados pela impressora são LPD, RAW e WSD (Web Services on Devices).
        Para alterar os números de porta do protocolo Alterando os números de portas
        1
        Inicie o Remote UI e faça o logon no modo Administrador Sistema. Iniciando o Remote UI
        2
        Clique em [Settings/Registration].
        3
        Clique em [Network Settings] [TCP/IP Settings].
        4
        Configure os protocolos de impressão.
        Configurando o LPD ou RAW
        1
        Clique em [Edit] em [LPD Print Settings] ou [RAW Print Settings].
        2
        Defina as configurações conforme necessárias.
        [Use LPD Printing]
        Marque a caixa de seleção para imprimir usando LPD. Desmarque a caixa de seleção se não quiser usar a impressão LPD.
        [Use RAW Printing]
        Marque a caixa de seleção para imprimir usando RAW. Desmarque a caixa de seleção se não quiser usar a impressão RAW.
        3
        Clique em [OK].
        Configurando o WSD
        1
        Clique em [Edit] em [WSD Settings].
        2
        Defina as configurações conforme necessárias.
        [Use WSD Printing]
        Marque a caixa de seleção para imprimir usando WSD. Desmarque a caixa de seleção se não quiser usar a impressão WSD.
        [Use WSD Browsing]
        Marque a caixa de seleção para obter informações sobre a impressora a partir do computador através do WSD. Esta caixa de seleção é marcada automaticamente quando a caixa de seleção [Usar a impressão WSD] está marcada.
        [Use Multicast Discovery]
        Marque a caixa de seleção para definir a impressora para responder a mensagens de descoberta multicast. Quando a caixa de seleção estiver desmarcada, a impressora permanece no modo de suspensão mesmo quando ele recebe uma mensagem de descoberta multicast da rede.
        3
        Clique em [OK].
        5
        Reinicie a impressora.
        Desligue a impressora, espere pelo menos 10 segundos e ligue novamente.
         
        Configurando dispositivos de rede WSD em Windows Vista/7/8
        Instale o driver da impressora de acordo com o procedimento usando as portas WSD descritas no Guia de instalação do driver de impressora.
