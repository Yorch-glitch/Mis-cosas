        Inicializando as configurações das preferências
        Você pode inicializar as configurações do menu [Preferences] do Remote UI (Lista de definições do menu) para restaurá-las com as configurações padrão de fábrica.
        1
        Inicie o Remote UI e faça o logon no modo Administrador Sistema. Iniciando o Remote UI
        2
        Clique em [Settings/Registration].
        3
        Clique em [Initialize Setting Information] [Initialize Menu].
        4
        Selecione as configurações para inicializar e clique em [Initialize].
        [Menu to Initialize]
        Selecione as configurações para inicializar da lista suspensa. Selecione [Initialize All] para inicializar [Display Settings] e [Timer Settings].
        5
        Clique em [OK].
