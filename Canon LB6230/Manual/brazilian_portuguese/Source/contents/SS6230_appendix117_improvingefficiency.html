        Melhorando a eficiência
        Gerenciamento remoto com a janela status da impressora e o Remote UI
        A janela de status da impressora e o Remote UI permitem gerenciar a impressora remotamente a partir do computador em sua mesa. Assim, pode-se monitorar o estado da impressora e verificar informações de erro a partir do computador. Sempre que ocorre um erro de impressão, a janela de status da impressora aparece automaticamente para informar que houve um erro, usando mensagens e animações fáceis de entender. Isso poupa tempo e trabalho, pois elimina a necessidade de o usuário se deslocar do computador até a impressora. O Remote UI simplifica a configuração da impressora e permite ajustar várias opções de configuração de rede.
        Para obter mais informações sobre a janela de status da impressora, consulte Janela de Status da Impressora.
        Para obter mais informações sobre o Remote UI, consulte Usando o Remote UI.
        Grave suas configurações favoritas e restaure-as sempre que quiser
        Todo o mundo no escritório usa a impressora. Se registrar as configurações mais usadas como configurações padrão, você poderá usá-las sempre que quiser. As combinações mais usadas também podem ser gravadas em perfis, que podem ser chamados com uma única ação, ou seja, seleciona-se o perfil em vez de ajustar todas as configurações a cada impressão.
        Para mudar as configurações de impressão padrão: Alterando as configurações padrão
        Para salvar as configurações de impressão mais usadas em perfis: Registrando combinações de configurações de impressão frequentemente usadas
        Poupe tempo com atalhos
        Se houver muitos documentos para imprimir, é melhor imprimi-os todos de uma vez. O Canon PageComposer permite agrupar vários documentos e imprimi-los todos de uma vez. Assim, pode-se poupar tempo e trabalhar de forma mais eficiente.
        Para obter mais informações sobre esta função, veja Combinando e Imprimindo múltiplos documentos.
