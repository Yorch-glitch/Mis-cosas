        Instalação
        Esta seção explica como instalar o driver da impressora no computador e como configurar a impressora e prepará-la para imprimir. O driver da impressora é o software necessário para utilizar a impressora. Leia esta seção e instale o driver da impressora corretamente.
        Instalação a partir do CD-ROM ou DVD
        Instale o driver da impressora a partir do CD-ROM ou DVD de software do usuário fornecido com a impressora. Realize o procedimento de instalação desde a conexão da impressora ao computador à instalação do driver de impressora. Instalação a partir do CD-ROM ou DVD
        Instalação após download do site de Canon
        A versão mais recente do driver da impressora pode ser baixada do site da Canon. Baixe um drive se, por exemplo, o sistema operacional de seu computador não suportar os drivers em seu CD-ROM ou DVD. Instalação após download do site de Canon
         
        Adicionando uma impressora em rede WSD
        No Windows Vista, 7, 8, Server 2008 ou Server 2012, o WSD (Web Services on Devices) pode ser utilizado para adicionar uma impressora de rede. Instalando para uso de WSD
