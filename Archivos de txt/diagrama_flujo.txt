SISTEMA DE VIDAS
===============================================================================

┌─────────────────────────────────────────────────────────────────────────┐
│  REGLAS:                                                                │
│  - 5 vidas iniciales                                                    │
│  - Se resta 1 vida por respuesta incorrecta en nivel                   │
│  - Se recupera 1 vida cada 30 minutos                                  │
│  - Máximo: 5 vidas                                                      │
│  - Timer en tiempo real (threading)                                     │
│  - Si vidas = 0: no se puede jugar nivel o examen                       │
└─────────────────────────────────────────────────────────────────────────┘

    ┌──────────────────────────────────────────────────────────────┐
    │  Flujo de recarga:                                              │
    │  1. Usuario pierde vida (vidas -= 1)                            │
    │  2. Si vidas == 4 o primera vez: registrar ultima_recarga      │
    │  3. Timer verifica cada segundo:                                │
    │     - minutos_pasados = ahora - ultima_recarga                 │
    │     - vidas_a_recuperar = minutos_pasados // 30                │
    │     - Si vidas_a_recuperar > 0:                                 │
    │       * vidas = min(5, vidas + vidas_a_recuperar)               │
    │       * Actualizar ultima_recarga                               │
    │       * Actualizar BD                                           │
    │       * Actualizar UI                                            │
    │  4. Si vidas == 5: detener timer                                │
    └──────────────────────────────────────────────────────────────┘
